# Changelog

What changed in each release of Tikko, newest first. Marketing and analytics agents read this
file to connect changes in the numbers (installs, trials, conversion) to what shipped, so keep
it accurate.

Format: one section per App Store version or over-the-air (OTA) update, with the date it went
live and plain-language bullets that say what a user would notice. Mark anything that touches
onboarding, the paywall, pricing, notifications, or the App Store listing, because those move
the numbers.

## Unreleased
- "Rate Tikko" in Settings now opens the App Store review page.
- App Store listing links (privacy policy and support) now point to gettikko.com.

## 1.0.1 (2026-11-25)
- **Onboarding:** new "Where did you hear about Tikko?" step (attribution).
- **Ratings:** the rating prompt can now appear after a 4–5 day rating on the evening recap.
- **Paywall:** offer code redemption.
- Day view uses three-colour bars (focus / neutral / drain).
- Over-the-air updates enabled.
- **Listing:** new App Store screenshots; keywords updated.

## 1.0 (2026-11-26 public release; built 2026-11-16 to 2026-11-24)
- Hourly check-ins with one-tap logging from the notification; 14+ activities including Sleep & naps and Hobbies & music.
- Day timeline, insights, evening recap ("Your day with Tikko") with one suggestion for tomorrow.
- Tikko mascot with moods; streaks.
- **Onboarding:** personal quiz and "years of your life" moment.
- **Paywall:** hard paywall, $39.99/year with 3-day trial or $4.99/month (RevenueCat).
- In-app privacy policy and terms.
- Anonymous analytics (PostHog).
